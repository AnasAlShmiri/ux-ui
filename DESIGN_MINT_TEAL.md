# Yerani — Mint + Teal High-Fidelity v4

Brand palette: `#ECFAF6` canvas, `#0EA184` brand, `#0F8579` accessible control, `#11776D` hover, `#B4DFDD` accents.

Mobile views are for patients/doctors/nurses. Admin views are web-only.

This is an HTML/CSS/JavaScript prototype: appointments, AI recommendations and medical data are not connected to a backend. All figures are demonstration data.

The theme is appended after existing styles; original pages and navigation remain intact. Mobile mock device status bars and evaluator role-switch banners are removed from markup.
