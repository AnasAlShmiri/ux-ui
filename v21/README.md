# يرعاني V21 — نسخة UX/UI جديدة مبسّطة

هذه نسخة مستقلة مبنية من الصفر في مجلد \`v21/\`. لا تغيّر إصدار V20 السابق.

## تشغيل
افتح \`v21/index.html\` في المتصفح مباشرة. ويمكنك فتح أربعة أدوار من شريط العرض: **المريض، الطبيب، الممرض، الإدارة**. لا يوجد ممثل زائر.

## المتطلبات المغطاة في واجهة المعاينة
- خدمات المريض: الوصول المباشر لحجز طبيب أو اختيار خدمة تمريض أو الملف الطبي أو المواعيد.
- التمريض: **نوع الخدمة دون تقييم أو نجوم** ← قائمة الممرضين المطابقين مع **تقييم كل ممرض** ← فتح نموذج الطلب مباشرة.
- الطبيب: قائمة الأطباء مع تقييم الطبيب نفسه، الاختيار، الاستعلام عبر واتساب.
- نموذج طلب واحد صغير للموعد والمنطقة، من داخل الواجهة دون سلسلة صفحات، مع معاينة الطلب وحالة معلّقة.
- متابعة الحجز والتعديل والإلغاء ومعاينة قبول مقدم الخدمة وإتمامها (العمليات على الذاكرة فقط).
- تقييم الطبيب أو الممرض فقط بعد اكتمال الزيارة (تجربة مؤقتة لا تغير متوسط تقييمه).
- ملف طبي واحد للمريض: بيانات، تاريخ مرضي، تشخيص وتعليمات الطبيب، ما نفّذه الممرض، القياسات، الوصفات، الفحوصات، تسلسل زمني.
- نموذج الطبيب لتوثيق التقييم والتعليمات والوصفة والفحوصات؛ نموذج الممرض لتوثيق التنفيذ والقياسات دون تعديل قرارات الطبيب.
- الإشعارات والشكاوى والاعتراض المالي وإدارة الخدمات والأسعار واعتماد الكادر، وكلها معاينات.
- مساعد إرشادي تجريبي بالكلمات المفتاحية لتوضيح شاشة توجيه التخصص، **ليس AI طبيًا فعليًا ولا تشخيصًا**.
- رابط واتساب خارجي برسالة **عامة فقط** دون بيانات مريض، ودون رقم افتراضي. يختار المستخدم جهة الاتصال بنفسه.

## حدود التنفيذ الصريحة
- جميع الأسماء والتقييمات والأرقام والأسعار والأوقات والسجلات **بيانات وهمية للعرض فقط**.
- لا يوجد Backend أو قاعدة بيانات أو هوية حقيقية أو صلاحيات مفعلة أو حفظ دائم أو طلب حجز حقيقي أو دفع أو اعتماد مهنة.
- التغييرات داخل المعاينة في ذاكرة الصفحة وتُعاد إلى بيانات النموذج عند إعادة تحميلها.
- لا يتم رفع أي ملفات، بل يُعرض اسم الملف فقط في الواجهة.
- فتح واتساب لا يُرسل رسالة تلقائيًا، ولا يضمن الوصول لمقدم الخدمة.
- للإطلاق الفعلي: بناء API وهوية وتفويض بالأدوار RBAC وتدقيق سجل طبي وموافقات وضبط الوصول ورفع آمن وحفظ حجوزات وتقييمات موثّق، تحقق من التراخيص وأوامر الطبيب، واختبارات سريرية وأمنية.

## ضمان سهولة الاستخدام
- أربع إجراءات مباشرة من الرئيسية.
- اختيار التمريض بخطوتين: الخدمة ← الممرض؛ ثم نموذج حجز واحد.
- وضوح نوع الخدمة مقابل مقدم الرعاية؛ النجوم للمقدم فقط.
- أزرار كبيرة وتصميم عربي RTL متجاوب مع لوحة مفاتيح ووسوم حقول.
- فصل واضح بين الدور السريري للطبيب والتنفيذ للممرض.
