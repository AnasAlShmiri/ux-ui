# يرعاني V21 — مراجعة المتطلبات والمنطق

## النطاق
نسخة جديدة بواجهات عربية RTL في `v21/index.html`. تم تحسين التوافق مع توثيق المشروع (المتطلبات الوظيفية وأدوار المريض والطبيب والممرض والإدارة)، دون الادعاء أن هذا تنفيذ إنتاجي.

| المتطلب | تمثيله في النموذج | ما يلزم لتشغيل فعلي |
|---|---|---|
| المريض يختار المستفيد والخدمة ومقدم الرعاية | نموذج طلب واحد مع قائمة مستفيدين مرتبطة بحساب العرض | حسابات فعلية، تحقق علاقة المستفيد وبيانات آمنة |
| طلب وموعد وعنوان وتكلفة | حقول قليلة؛ تكلفة نموذجية وتعارض وقت محلي | توافر مزود فعلي، سياسة حجز/إلغاء وتأكيد |
| تعديل وإلغاء ومتابعة | الحالات المعلقة والمؤكدة فقط؛ زيارة مكتملة تُغلق | عمليات معتمدة وسجل تدقيق |
| تقييم مقدم الرعاية بعد الخدمة | نجوم للطبيب والممرض فقط، ومتوسط متغيّر في الجلسة | تقييم مرتبط بزيارة موثقة وضوابط إساءة |
| ملف طبي فردي | بيانات مستقلة لكل مستفيد وتحديثات مشتركة ضمن نفس الملف | سجل سريري محمي وإسناد دقيق للزيارات |
| الطبيب يوثّق التشخيص والخطة | نموذج تعليمات ووصفة وجرعات ومواعيد متابعة وفحوص | صلاحية طبيب، توقيع/توثيق، تحقق من الأدوية |
| الممرض ينفذ ويكتب تقريرًا | تقارير وقياسات وتنفيذ فقط من الأدوية المدرجة | التحقق من أوامر طبية صالحة وتكليف ومساءلة |
| واتساب للتنسيق | رابط عام يفتح واتساب دون رقم معين | جهة اتصال موثقة وموافقة، وعدم إرسال بيانات حساسة |
| إشعارات وتذكير أدوية ومواعيد | ملخص يُعرض عند فتح النافذة وزر تفعيل تجريبي | خدمة مجدولة وتنبيهات فعلية وموافقة |
| الاعتماد والإدارة | مستند اسمي تجريبي، قرار وسبب رفض، مستخدمون وأسعار وشكاوى | تحقق تراخيص حقيقي وحفظ آمن |
| مساعد توجيه الأعراض | مطابقة كلمات توضيحية للتخصص وتحذير طوارئ | نموذج معتمد ومراجعة سلامة؛ لا تشخيص |

## اختبار المحاكاة (27 حالة ناجحة)
1. الشاشة الرئيسية وأربع وجهات تنقل للمريض.
2. عرض الخدمات دون تقييم للخدمة.
3. تصفية الممرضين حسب الخدمة.
4. فتح طلب الممرض وربطه بمستفيد مختلف.
5. منع عرض حجز ممرض آخر في لوحة الطبيب.
6. فصل السجل الطبي لمستفيدين.
7. إضافة وتحديث تعليمات الطبيب ووصفة تجريبية.
8. نقل التقرير التجريبي الذي كتبه الممرض إلى الملف الموحد.
9. إظهار التقييم بعد الزيارة وتغيير متوسط العرض.
10. طلب اعتماد الكادر ورفضه مع توضيح السبب.
11. منع حجز الوقت نفسه مرتين عند مزود الرعاية نفسه.
12. منع عرض الزيارات غير المسندة لمقدم الرعاية.
بقية الفحوص مشابهة لخطوات تفصيلية ضمن المسارات نفسها.

## حدود الجودة المتبقية
- لا تتوفر اختبارات بصرية داخل المتصفح أو على أجهزة فعلية في هذه المراجعة.
- لا يوجد Backend أو مصادقة فعلية أو تشفير أو تخزين بيانات.
- التحقق من الصلاحيات في JavaScript داخل الواجهة ليس ضمانًا أمنيًا.
- قبول طلب زيارة، دفع نقدي، تقييم، تذكير، أو اعتماد كادر كلها أمثلة محلية لا تُرسل للجهات المعنية.
- أسماء الأطباء والممرضين والتقييمات والأسعار والأعراض والسجلات نموذجية.
- لا تُستخدم هذه المعاينة لاتخاذ قرارات علاجية أو تشغيل خدمات طبية حقيقية.

**التنفيذ الفعلي يجب أن يطبق هذه الضوابط على الخادم ويجتاز اختبارات الأمن والخصوصية والسلامة قبل الإطلاق.**
